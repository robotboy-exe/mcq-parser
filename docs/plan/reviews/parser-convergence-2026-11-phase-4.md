## Production investigation

1. **Text ownership → extraction → targets.** `splitRegions` strips the question number from the first line and puts that stem into the chunk (`core.js:233–265`). It also uses the widened `STIMULUS_INTRO_RANGE` to exempt some lines from normal instruction ownership. `parseQuestion` calls `extractStimuli` before matching and cleaning options (`core.js:938–961`). The marker run uses structural boundaries plus transparent intro/table/blank lines; `hasRangedIntro` can now make that run removable independent of evidence, and `stimulusMarkerRange` gets a `block` but no adjacency provenance (`core.js:580–713,745–842`). `applyStimulusFlags` then sorts/assigns `stimuli` metadata, looks up targets by question number and marks in-paste items or records `missing` (`core.js:889–922`). It trusts the extracted numbers; it cannot tell a date fragment from a legitimate target.
2. **Loading and persisted state.** The deployed page loads the pinned core then manual adapter (`deployed/admin_questions.php:1050–1051`); `ocr_helper.js:16–25,55–126` fills four native options, keeps the range on the source item, stores `{items,i}` and known metadata, and does not run queue-level flagging. The key artifact calls `core.parsePaste` (which does queue flagging), writes `ansKey` separately, stores queue `how` and per-tab `ocrPaste`, and fills the form/key (`src/bookmarklets/key/entry.js:139–165,463–535`). The stimulus artifact uses canonical splitting, `parseQuestion` and `applyStimulusFlags` on Load, stores queue `batchId`, and builds the plan from `stim.nums` (`src/ui/ui.js:243–265,309–385,1157–1229`). Files remain in-memory. All used the exact candidate core; none changed a storage key, native form field, or product-specific save policy in this diff.
3. **Network/server path.** A paste/Load updates the queue and native DOM fields synchronously. A native Submit sends those values through PHP CSRF, four-option checks and PRG (`deployed/admin_questions.php:357–388,436–474,528–556`; `ocr_helper.js:115–126` handles next-load settlement). In the stimulus product, the wrong `nums` also become the default attachment range; Attach parses that range with `parseStimulusRange` and the image gate checks for items outside the queue. The highest-risk interactions exercised were extraction before option ownership, a prose-delimited fallback being mistaken for adjacency, shared range syntax affecting RM01 even without a marker, and numeric fragments becoming default image destinations.
